# Django-Todo-App
A simple Todo application built with Django and Bootstrap 5. This app allows users to add, complete, and delete tasks with a clean and responsive interface. It’s a full CRUD web application that demonstrates Django models, views, templates, and basic frontend styling with Bootstrap.

Features
Add new tasks with title and description
Mark tasks as Completed
Delete tasks

Responsive UI using Bootstrap 5
Dynamic rendering of tasks using Django templates
Learn by doing: Python + Django + Frontend integration

Technologies Used
Backend: Python, Django 5.2
Frontend: HTML, CSS, Bootstrap 5
Database: SQLite (default Django DB)
Other: Django Templates, Django ORM
